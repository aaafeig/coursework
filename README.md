# Проект: Анализ Финансовых Транзакций

## Описание
Данный проект предназначен для анализа финансовых транзакций, вычисления трат по категориям, средних расходов, поиска транзакций и формирования отчетов в формате JSON. Включает функции работы с кэшбэком, округлением сумм и отображением курсов валют и акций.

## Основные функции

### 1. spending_by_category
- Принимает DataFrame с транзакциями, категорию и дату (по умолчанию текущая).
- Возвращает DataFrame с колонками: **Категория, Дата платежа, Сумма операции с округлением** за последние 3 месяца от указанной даты.

### 2. spending_by_weekday
- Принимает DataFrame с транзакциями и дату (по умолчанию текущая).
- Рассчитывает средние траты за день в течение 3 месяцев от введенной даты.
- Возвращает DataFrame с колонками: **Дата платежа, Средняя трата**.

### 3. write_profitable_cashback_categories
- Принимает данные, год и месяц.
- Возвращает JSON с наиболее выгодными категориями для кэшбэка.

### 4. investment_bank
- Принимает месяц, список транзакций и лимит округления.
- Округляет суммы транзакций до указанного лимита и возвращает разницу между фактической и округленной суммой.

### 5. search_to_str
- Принимает список транзакций и строку поиска (категория).
- Возвращает список всех транзакций, относящихся к указанной категории.

### 6. names_find
- Принимает список транзакций.
- Ищет и возвращает все транзакции, связанные с введенным именем.

### 7. tel_num_find
- Принимает список транзакций.
- Ищет и возвращает все транзакции, связанные с введенным номером телефона.

### 8. write_json_gl
- Принимает строку с настройками времени.
- Возвращает JSON с отфильтрованными транзакциями (от введенной даты до начала месяца).
- Включает информацию о картах (траты, кэшбэк), топ-5 транзакций, курсы валют и акций.

### 9. write_json_sob
- Принимает дату и период (по умолчанию неделя).
- Фильтрует транзакции по указанному диапазону (**неделя, месяц, год, все транзакции до даты**).
- Возвращает JSON с информацией о расходах, поступлениях, курсах валют и акций.
